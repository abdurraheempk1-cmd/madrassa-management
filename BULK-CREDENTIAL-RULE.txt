Bulk student credentials

Username: student first name. If already used, append 2, 3, 4...
Example: بشریٰ, بشریٰ2, بشریٰ3

Temporary password: 4-digit birth year repeated twice.
Example: 1998 -> 19981998

If DOB is missing, the row is not imported until Admin corrects the DOB or sets a valid temporary credential workflow.

Run sql-parts/08-bulk-student-credentials.sql once.
